ระบบเช็คราคา (สแกนบาร์โค้ด / คิดเงิน / ทอนเงิน)

1) Google Sheets
   - สร้างชีตใหม่ นำเข้า products-sample.csv (ไฟล์ > นำเข้า) หรือพิมพ์เอง
   - คอลัมน์ A = บาร์โค้ด, B = ชื่อสินค้า, C = ราคา, D = หมวดหมู่ (แถว 1 เป็นหัวตาราง)
   - หมวดหมู่เว้นว่างได้ สินค้าที่ไม่มีหมวดจะอยู่กลุ่ม "ไม่ระบุหมวดหมู่"
   - เลือกคอลัมน์ A ทั้งหมด แล้วตั้งรูปแบบเป็น "ข้อความธรรมดา" (รูปแบบ > ตัวเลข > ข้อความธรรมดา)
     เพื่อไม่ให้เลข 0 นำหน้าหาย

2) Apps Script
   - ในชีต: ส่วนขยาย > Apps Script > วางโค้ดจาก Code.gs ทับของเดิม
   - แก้บรรทัด var PIN = '1234'; เป็นรหัสของคุณเอง (ใช้ยืนยันตอนเพิ่ม/แก้ไข/ลบสินค้าในแอป)
   - ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท "เว็บแอป"
     เรียกใช้ในฐานะ: ฉัน | ผู้มีสิทธิ์เข้าถึง: ทุกคน > ทำให้ใช้งานได้ แล้วอนุญาตสิทธิ์
   - คัดลอก URL ที่ลงท้ายด้วย /exec

3) หน้าแอป
   - เปิด index.html หาบรรทัด var API_URL = ''; แล้ววาง URL ตรงนั้น
   - อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages (หรือ Cloudflare Pages / Netlify) ซึ่งเป็น https และฟรี
   - เปิดลิงก์บนมือถือ > เมนูเบราว์เซอร์ > "เพิ่มลงหน้าจอหลัก"

เมื่อแก้ราคาในชีต: กดปุ่มรีเฟรชมุมขวาบนของแอป (หรือเปิดแอปใหม่) ราคาจะอัปเดต
หมายเหตุ: ถ้าแก้โค้ด Apps Script ภายหลัง ต้อง "จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่" URL เดิมจึงจะได้โค้ดใหม่

เพิ่ม/แก้ไขสินค้าในแอป
   - แท็บ "เพิ่มสินค้า" > เปิดกล้อง > สแกนบาร์โค้ด > กรอกชื่อและราคา > บันทึก
   - ถ้าบาร์โค้ดมีอยู่แล้ว ฟอร์มจะขึ้นชื่อและราคาเดิมให้แก้ได้ (และมีปุ่มลบสินค้า)
   - ครั้งแรกกรอก PIN ในช่อง "รหัส PIN" แอปจะจำไว้ในเครื่องนั้น
   - ต้องมีอินเทอร์เน็ตตอนบันทึก (ไม่มีเน็ตจะบันทึกไม่สำเร็จและแจ้งเตือน)
